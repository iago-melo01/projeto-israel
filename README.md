## Sistema de gerenciamento de tarefas no estilo Kanban, inspirado no Trello, desenvolvido como projeto da disciplina de CI/CD e DevOps.

## A aplicação em si é propositalmente simples. O foco do projeto está em como ela é construída, testada, empacotada, entregue e monitorada, aplicando na prática os conceitos de integração contínua, entrega contínua e cultura DevOps.

# Objetivos do projeto
Desenvolver uma API REST funcional para gestão de quadros, listas e cartões.
Automatizar lint, testes e build a cada push e Pull Request.
Empacotar a aplicação em containers Docker e publicá-la em um registry.
Realizar deploy automático em ambientes de staging e produção.
Adicionar monitoramento, métricas e verificações de segurança ao pipeline.
Documentar todo o processo de forma que qualquer pessoa consiga reproduzir o ambiente.
